# Visual contract: SNR-stratified AUROC and Recall

- **Artifact:** two-panel SNR performance comparison figure.
- **Target format:** standalone PNG and editable SVG for the v2 research report.
- **Core claim:** display how each evaluated condition changes across six positive-sample target-SNR bins; no inferential claim is encoded.
- **Reviewer question:** does the relative performance of BCSC-based conditions and waveform baselines vary at low SNR?
- **Evidence layer:** robustness / stratified source-data summary.
- **Source data:** `metrics/snr_results.csv`, generated from the completed 7,000-sample, five-fold OOF predictions.
- **Statistics / uncertainty:** point estimates only. Per-bin confidence intervals were not computed and are not shown.
- **Figure prototype:** coordinated two-panel line chart with a shared categorical legend.
- **Panel map:** left: AUROC by target-SNR bin; right: Recall by target-SNR bin, using the validation-fold Balanced-Accuracy threshold for each test-fold prediction.
- **Exact label inventory:** `AUROC`, `Recall`, `Positive target SNR (dB)`, `Low-SNR primary range`, and the seven condition labels in the CSV-derived mapping.
- **Color and accessibility:** Okabe-Ito-derived colors, plus unique line styles and markers for grayscale legibility. Gated fusion uses blue consistently; waveform uses dark neutral gray.
- **Caption role:** identify this as SNR-stratified descriptive evidence and state the data source.
- **Output formats:** `figures/snr_auroc_recall.png`, `figures/snr_auroc_recall.svg`.
- **Traceability:** generated by `plot_snr_auroc_recall.py` from `metrics/snr_results.csv`.
