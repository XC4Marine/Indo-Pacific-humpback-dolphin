# 实验23-v3：单层波形Transformer与实时梯度监控

本报告只使用已完成的5个模型折实际预测：训练种子为20260826、34个录音组固定五折和7,000条变SNR波形。模型仅输入波形；Transformer Encoder为单层。测试fold为f、验证fold为(f+1) mod 5，最佳检查点按验证集`[-15,0)` dB AUROC选择；温度缩放与Balanced Accuracy阈值仅由完整验证集确定。
