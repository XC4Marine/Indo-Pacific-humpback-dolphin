# 第20实验 v5：深度展开式 BCSC 原型实验报告

## 1. 问题与范围

本实验检验六阶段可训练展开式 BCSC 能否在严格来源隔离下，改善共享源与逐事件信道恢复。可训练模型只在干净合成 clicktrain 上训练；测试输入为无噪声、−5 dB 和5 dB。模型推理阶段只读取 `clicktrain_raw.npy`，真值仅在推理完成后的独立评估阶段读取。

数据按69个原始来源组固定划分为48个训练组、10个验证组、11个测试组；测试集含16个 clicktrain。结果按每个 clicktrain 的10个事件取中位数，再在16个 clicktrain 上汇总。

## 5. 结果解释

1. 三个条件下，源相关的配对95%区间均低于零，当前可训练六阶段展开未达到 v4 independent 的源恢复水平。
2. 路径F1的配对95%区间也均低于零，说明当前可学习步长和阈值不足以保持 v4 的逐事件路径分辨能力。
3. 信道幅度RMSE的点估计对可训练展开更低，但三种条件的配对95%区间均包含零；因此不能据此主张其具有稳定总体改进。
4. 固定六阶段展开也低于完整迭代 v4，表明仅保留六个更新阶段会形成明显的优化预算瓶颈；当前实验不支持将性能差异单独归因于参数是否可学习。

## 6. 结论与下一步

该原型完成了严格来源隔离、盲推理和三种子评估链路，但当前六阶段配置没有优于完整 v4 independent BCSC。下一轮应优先增加展开阶段数或引入与 v4 收敛步骤匹配的初始化，再在相同留出划分上进行配对消融；在此之前，不应以该原型结果主张深度展开带来恢复性能提升。
