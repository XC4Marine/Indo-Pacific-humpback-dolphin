# 实验 v6：independent BCSC 的 clicktrain 稳定多径结构提取

## 范围

本报告覆盖 1 个 clicktrain。提取阶段仅复用 v4 independent BCSC 的盲提取源、十事件信道、重构和检测窗口，并在固定该源条件下进行残差块 bootstrap；真值仅在本评估阶段读取。因此，联合置信度是**固定已提取源的条件置信度**，不代表完整 BCSC 参数（尤其是源波形估计）的不确定性。

## 方法与固定参数

十事件候选按 0.03 ms 聚类，跨事件覆盖至少 6/10 的候选进入稳定结构池；直达径始终保留。每个样本进行 2 次固定种子的同步十事件条件残差块 bootstrap。BIC 在直达径与置信度最高的最多 5 条反射候选上枚举支持集；每个事件独立最小二乘重估幅度，复杂度项为 10K log N。

## 全量汇总

- 稳定结构 F1：中位数 1.000
- 稳定结构时延 MAE：中位数 0.00188 ms
- 逐事件路径 F1：中位数 1.000
- 重构 NRMSE：中位数 0.1450
- 置信度 Brier score：0.6667

最佳样本：`click_001_train_020_pulse_083`（稳定结构 F1=1.000）。

困难样本：`click_001_train_020_pulse_083`（稳定结构 F1=1.000）。

## 局限性

该流程不重采样或重估盲源，故不能用于完整 BCSC 参数不确定性推断。稳定性还依赖 v4 第一阶段候选能覆盖真实路径；没有被第一阶段发现的路径无法由 bootstrap 新建为 v6 候选。BIC 的独立事件幅度重估降低了稀疏收缩偏差，但仍受固定时延和窗口对齐误差影响。
