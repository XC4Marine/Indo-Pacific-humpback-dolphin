# v4 BCSC 高置信多径 bootstrap 小验证

## 问题与协议

本试验检验：对现有 BCSC 稀疏信道的路径候选进行残差块 bootstrap 后，仅保留稳定路径，是否能更接近事件真实多径结构和真实信道频响。

- 数据：由稳定哈希选出的 12 个 clicktrain，每个含 10 个事件。
- 方法：`single_click`、`independent`、`shared_support` 的既有全量 BCSC 盲提取产物。
- 提取侧：固定该方法已经盲估计的源 click；每事件对重构残差作 0.10 ms 循环块重采样，构造 50 个波形，并重新求稀疏信道。提取入口不读取任何真值资产。
- 稳定路径：相对原始候选的 0.03 ms 一对一匹配；保留直达径；反射径须同时满足检出率至少 0.90、50 次 bootstrap 的 Wilson 95% 下限至少 0.80。
- 真值侧：独立读取 `event_channels.npz`，计算 Path Precision、Recall、F1、以及仅由高置信脉冲构造的信道 20--190 kHz 幅频 RMSE。每组内先取 10 事件中位数，再以 12 个 clicktrain 为单位做 2,000 次 bootstrap。

这里的 bootstrap 是**条件于已估源 click**的通道稳定性检查；它并不表示对完整盲反卷积（包括源估计不确定性）的置信区间。

| single click | 0.830 [0.788, 1.000] | 0.500 [0.500, 0.667] | −0.300 [−0.343, −0.150] | 11.064 [10.502, 11.383] | 11.057 [10.540, 11.363] | −0.005 [−0.023, 0.017] |
| independent | 0.830 [0.775, 1.000] | 0.500 [0.500, 0.667] | −0.300 [−0.368, −0.150] | 11.064 [10.502, 11.454] | 11.057 [10.541, 11.389] | −0.006 [−0.044, 0.017] |
| shared support | 0.667 [0.575, 0.781] | 0.500 [0.475, 0.575] | −0.158 [−0.300, 0.000] | 10.723 [10.423, 11.255] | 11.057 [10.543, 11.361] | +0.055 [−0.062, 0.183] |

## 诊断

- 三个方法经筛选后的路径精确率中位数均为 1.0，但这是以漏检反射径为代价。
- `single_click` 与 `independent` 的反射径召回中位数由 1.000 降至 0.333；`shared_support` 由 0.583 降至 0.333。
- 120 个事件中，仅保留直达径的事件数分别为 69（single click）、69（independent）和 87（shared support）。因此高置信脉冲信道常退化为直达径模型，无法改善真实信道的频响形状。
- 结论：当前严格规则适合作为“可靠直达径/极稳定反射径”的报告标签，但不适合作为直接替换原稀疏信道的结构恢复器，也不支持其会改善频率响应恢复的结论。

## 建议的下一步

若目标是获得可用的稳定多径结构，应将 bootstrap 由硬剔除改为置信度加权，并在独立校准集上选择阈值：例如比较 Wilson 下限 0.50、0.60、0.70、0.80，使用 Path F1 或反射径 F1 选择阈值，同时保留路径系数的 bootstrap 中位数和区间。这样可让“稳定性”抑制不稳定候选，而不会把弱但真实的反射径全部删除。
